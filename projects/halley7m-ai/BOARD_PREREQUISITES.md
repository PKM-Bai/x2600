# AI 终端板级前置条件

本表记录资料与实际验收的区别。日期：2026-10-23。

| 项目 | 已有依据 | 尚需取得的实测或材料 |
| --- | --- | --- |
| Air1103 | 用户已用 Air8000 / Air780EHM / Air1601 验证独立录放音 | 实际板版号、固件版本、X2600 UART 接线、电平与尾音时间 |
| J6 UART5 | 底板原理图第7页：9脚PC7、10脚PC8 | 与GT911硬冲突，禁止用于Air |
| Air候选UART | UART4 PB24/PB25优先，其次UART5 PB26/PB27 | 实际引出、空闲状态、IO电压及2 Mbps信号验证；未冻结前不启用UART |
| 以太网 | X2600 U-Boot GMAC0；实板MDIO地址0/ID02430c54，PC15复位及MPLL分频50MHz诊断通过 | RMII模式差异、DMA/cache帧收发、DHCP及外网 |
| SWT6621-SH | 用户选定J10现有模块 | SH匹配主机驱动、firmware、NV/校准数据及控制脚；SL/AP6212资料不能替代 |
| DTRNG | 本地X2600手册章41及CLKGR0 bit27已核对；实板三次256字采样完成，无相邻重复/全0/全1 | 持续熵服务及健康检测；变化统计不等于熵质量验收 |
| 云端 | DeepSeek官方HTTPS/SSE已完成单轮及12轮真实文字验收，密钥仅本机/TF保存 | 百炼真实WSS混合语音和8轮instructions背景方案仍未验收 |
| NOR | 当前应用区[0x40000,0x278000)，2326528 B | AI候选容量、完整回读及10次物理冷启动；前期只RAM装载 |

Air UART接线必须先冻结接线表。复用现有板载接口的诊断依据已核对的板图和手册进行，
没有板测证据的项目不标记通过。GMAC的RMII模式字段存在手册4/U-Boot2的差异，
当前MDIO诊断保留原模式，尚不启用帧收发。
源依据：仓库`Halley7`底板图、`docs/HALLEY7-M-KIT硬件规格.md`、
`u-boot-ingenic/include/configs/x2600m_halley7.h`、播放器NOR安装记录。

## 实施顺序

P0资料/PC协议 → P1独立固件与TF资源 → P2以太网/TLS → P3文字 → P4语音。
Wi-Fi从P0并行取证，完成P5后才能进入P6双网联合与独立启动验收。
缺失资料只阻塞依赖该资料的工作包；不将桩函数、主机模拟或交叉编译当成实板通过。
