# 探针证据与场景模板

`deepseek-live-single-20261023.report.json` 和 `deepseek-live-12turns-20261023.report.json` 是真实 DeepSeek 调用的脱敏统计，不是模拟输出。单轮和 12 轮场景均在 PC 上执行，不能用于宣称设备或语音验收通过。

`bailian-mixed12.example.json` 只是待执行的场景模板。创建本机 `audio/` 目录，准备下列 16 kHz、单声道、s16le、无头 PCM，每段不超过 30 秒：

| 文件 | 建议朗读内容 |
| --- | --- |
| `02.pcm` | 这是第二轮连通性测试，请只回复数字二。 |
| `04.pcm` | 这是第四轮连通性测试，请只回复数字四。 |
| `06.pcm` | 这是第六轮连通性测试，请只回复数字六。 |
| `08.pcm` | 这是第八轮连通性测试，请只回复数字八。 |
| `10.pcm` | 本轮的新标记是绿色风铃，请记住。 |
| `12.pcm` | 你好，请简短介绍自己。 |

待真实运行后检查第 10 轮只携带第 2～9 轮文字，第 12 轮背景为空，以及第 9、11 轮的跨模态事实追问。不要仅凭模型声称“我忘记了”判断历史淘汰；以请求中的历史列表和新 session ID 为准。

离线 transport 测试事件由 `tests/test_ai_cloud_probe.py` 和 `tests/test_ai_deepseek_probe.py` 生成；它们不冒充真实服务器返回事件。
