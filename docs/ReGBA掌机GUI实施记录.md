## 中文 ROM 文件名验收基线（a85324e3）

旧版 UI 按 UTF-8 解码，而 FatFs 的 CP437 窄字符 API 返回 OEM 文件名；同时原精简字库只保留菜单文字，中文 ROM 名可能成为乱码、短名或缺字方框。当前代码启用 `_LFN_UNICODE=1`，FatFs 使用 UTF-16 长文件名，文件任务作为唯一边界将应用 UTF-8 路径严格转换为 UTF-16，并将目录项转回 UTF-8。扫描、打开、重命名和存档均使用同一边界，非法 UTF-8 / UTF-16 或空间不足报错，不以截断后的路径继续访问。

字库改为静态编入仓库 Unifont 源中可用的 **34869 个 BMP 字形**，来源与 GPL 注记保留，覆盖常用 GB2312 / Big5 简繁汉字。它不是全部 Unicode 字库，仓库源中没有的扩展 A 等字形以及非 BMP 字形仍以方框显示；文件名编码处理和可见字形覆盖是两件不同的事。文件名单项最多 **255 UTF-8 字节**，文件层路径最多 **512 字节**，ROM 启动入口保留当前 **511 字节**上限；例如常用汉字通常各占 3 字节，不能按“255 个汉字”理解。仅屏幕省略使用 UTF-8 字符边界，真实路径不截断。

## 界面与操作

以下操作按当前已装 NOR 的 `178853ea` 修订说明；各版本验收范围见本文前面的记录。

界面沿用 720×1280 竖屏双缓冲，深紫背景、薄荷选中行，最多显示 8 行；菜单正文为 32px，标题为 48px。游戏画面仍为 240×160 按 3 倍最近邻缩放到 `(0,400)` 的 720×480 区域。菜单关闭时清理两个缓冲中的旧界面，再恢复游戏区域。

| 场景 / 按键 | 操作 |
|---|---|
| 游戏中 Y | 在帧边界暂停，等待已在途保存完成后打开菜单，不新提交当前进度；Y 不映射到 GBA 按键 |
| 游戏库 A / B | A 进入目录或启动所选 `.gba`；B 返回上级目录，在根目录且仍有已载入游戏时可返回游戏 |
| 游戏库上下 / L、R | 上下选择，L/R 翻页；方向长按首轮等待 350ms，之后每 100ms 重复 |
| 游戏库 SELECT | 在 `/GBA/ROMS` 与 `/gba_game` 两个根目录间切换 |
| 游戏库 START | 打开资源路径页，B 返回 |
| 暂停菜单 A | 依次为：继续游戏、保存进度、读取存档、游戏设置、切换游戏、资源路径、退出游戏 |
| 暂停菜单 B / Y | 继续游戏 |
| 读取确认页 A / B | A 读取已有 `.sav` 并重新启动游戏，B 取消并返回暂停菜单；两次 A 之间须先松开 |
| 游戏设置上下 / 左右 / A | 上下选择音量、跳帧或速度，左右调整，A 同右键；B / Y 返回暂停菜单 |
| 错误 / 提示页 | 有可重试操作时 A 重试，B 返回；无重试操作时 A/B 返回 |

界面切换设释放门槛，须先松开当前按键和 Y，避免按住的 A 自动启动下一项，或 Y 打开菜单后立即恢复。ROM 列表保留可见子目录及 `.gba` 文件，支持子目录进入与返回、末页和边界修正。标准目录为空或不存在时尝试旧版目录；两处都没有游戏时回到标准目录，显示操作提示。ZIP 暂不支持，ROM 上限为 32MiB。

保存进度对应游戏原生电池存档 `.sav`，不是模拟器即时状态；游戏内尚未产生可保存进度时会显示说明。读取存档会放弃当前未保存的进度，重新启动当前游戏；启动后在游戏内选择继续游戏。退出游戏会在保存完成后释放 ROM，回到列表；切换游戏先保存当前游戏，保留原 ROM，待用户选择并成功加载下一游戏后运行。游戏声音由设置页调整，用户此前取消的音质专项调试接口不再保留。

## 资源路径与文件名

路径统一由 `core/resources.h` 定义，资源页使用同一组常量：

| 资源 | 路径 |
|---|---|
| 标准游戏库 | `/GBA/ROMS` |
| 旧版游戏库 | `/gba_game` |
| 原生存档 | `/GBA/SAVES` |
| 可选 BIOS | `/GBA/BIOS/gba_bios.bin`，仅接受准确 16384 字节；否则沿用内置 open BIOS |
| 游戏配置 | `/GBA/CONFIG/game_config.txt` |

标准和旧版根目录的 ROM 保持已有 `basename.sav` 名称，兼容现存存档；子目录或其他路径在文件主名后追加 ASCII 大小写折叠后的完整 ROM 路径 CRC32，避免不同目录同名游戏串档。例如 `/GBA/ROMS/RPG/Same.gba` 使用 `/GBA/SAVES/Same-6de1a93c.sav`。同一 FAT 路径的大小写变体采用相同 CRC；根目录中的同名游戏仍共用旧式存档名，这是保留旧存档兼容的既定行为。路径超长会报错，不截断后继续访问。

当前中文文件名代码采用 UTF-8 应用路径 / FatFs UTF-16 边界，并编入可用 Unifont BMP 字形，具体覆盖和字节限制见本文前面的修订节。此前 `3d721f71` 等旧 NOR / 历史版本仍为 CP437 API 与菜单精简字库；旧版中文菜单正常不作为新版中文 ROM 名的实板验收。

## 保存、任务归属与失败处理

GUI 控制、游戏执行、输入消费、视频绘制和 guest 存档读取归同一个模拟器任务所有。游戏在帧边界处理菜单请求，只等待已在途的保存完成，保持当前未保存进度供继续游戏或显式读档选择。最后一次修改后 2 秒自动提交和手动保存继续复用；提交时由模拟器任务生成 guest 状态一致的原生存档快照。保存工作任务持有快照，所有 FatFs 调用通过文件任务串行执行，其他任务不直接访问卡。

原生存档接受 **512、8192、32768、65536、131072 字节**五种长度，按游戏实际识别的 SRAM / EEPROM / Flash 类型加载。写入先生成 `.tmp`，检查写入、`fflush`、关闭 / FatFs 同步结果，再将已有文件轮换至 `.bak` 并替换正式 `.sav`；失败回滚或保留可恢复的备份。已有坏长度拒绝加载、上一版本恢复和错误传播继续保留。

显式保存、正常退出、切换游戏及普通停止仍须提交当前快照并等待最终同步。保存失败会阻止切换 / 卸载，保留旧 ROM 和 RAM 中尚未保存的进度，界面显示“保存未完成”并提供重试。手动读取存档则在确认后预读最多 128KiB 的目标 `.sav`，检查成功才替换 guest 存档并重置已缓存的 ROM；不先将当前 RAM 写回覆盖读取目标，读取或长度检查失败也不重置当前 guest。ROM 存在性、长度、格式等预检失败不会先卸载原游戏；若新 ROM 加载阶段失败，界面以核心报告的实际 loaded 状态处理，不能承诺所有加载错误都保留原 ROM。

错误页覆盖卡未就绪、目录 / 文件不存在、ROM 过大、内存不足、路径过长、格式 / 存档大小错误、只读或拒绝写入、操作忙和读写失败。列表、保存中和加载进度均显示在屏幕，技术详情继续保留在控制台。Y 暂停 / 恢复、资源页返回及修正版保存 / 切换 / 退出已有实板证据；写入失败重试、存档中的实际游戏进度恢复等场景仍需专项验收。

## 屏上 CPU / FPS 与首次 NOR 安装（3d721f71 历史）

HUD 在上方黑边的第 320～383 行显示 `CPU` / `FPS`，游戏区域仍从第 400 行开始。CPU 使用已有 FreeRTOS 64 位 Idle 运行时间与墙钟之差，表示全系统非 Idle 占比；中断时间沿用运行时间统计口径，计入被打断的任务。FPS 以同一实际时间窗内完成的 GBA 帧计算，与约 30Hz 的 LCD 呈现 / 跳帧计数分开。数值保留一位小数，每个至少 1 秒的窗口最多发布一次，复用模拟器任务和现有双缓冲绘制，没有新增任务、动态分配或每秒任务遍历。
